# Device photos

Drop real photos of the companion running on hardware in this folder, then swap the
placeholders in the top-level README for them.

The README has commented-out `<!-- ![...](...) -->` lines next to each
`> **📸 Photo goes here**` block. Uncomment the image line and delete the placeholder
blockquote above it.

Suggested shots:

| Filename | Shot |
| --- | --- |
| `home-screen.jpg` | Home screen with a companion and speech bubble |
| `character-two.jpg` | A different character, for contrast |
| `neglected.jpg` | A Peckish or Neglected companion |
| `settings-picker.jpg` | The character picker in Settings |

Landscape orientation reads best in a README. Straight-on beats angled, and daylight or a
lamp behind you avoids the glare an e-ink panel picks up.
